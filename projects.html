Process

How I build.

  1. Sketch it. Decide what belongs on the page before writing a tag.
  2. Write the HTML. Structure first: header, nav, main, footer, headings, lists.
  3. Style it with CSS. One external stylesheet, one obvious place to change a colour.
  4. Test it. Keyboard, phone width, broken images, and a refresh with the network off.
